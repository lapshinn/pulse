# Пульс — локальный дашборд здоровья

Личная панель для данных Xiaomi / Mi Fitness. Интерфейс работает локально: React + FastAPI, без облака и внешней аналитики.

Сейчас дашборд открывается на синтетике на 90 дней. Реальный ZIP/CSV можно загрузить и проверить, но активация импорта появится после разбора вашего экспорта.

## Запуск

Нужны Python 3.10+ и Node.js 18+.

```powershell
cd "$env:USERPROFILE\Desktop\Дашборд"
.\run.ps1
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173). API: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Повторный запуск без переустановки зависимостей:

```powershell
.\run.ps1 -SkipInstall
```

## Что внутри

- Welcome-экран: `Открыть демо` или `Загрузить данные`
- Одна прокручиваемая страница: Сегодня, Нагрузка, Сон, Здоровье, BioAge
- Три демо-сценария в профиле: полные данные, короткая базовая линия, отсутствуют HRV/SpO₂
- Импорт ZIP/CSV показывает отчёт совместимости и не угадывает неизвестные колонки

## Тесты

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest

cd ..\frontend
npm test
npm run test:e2e
```

## Важно

Метрики — приближённые оценки, не медицинский диагноз. Mi Band не является медицинским прибором.

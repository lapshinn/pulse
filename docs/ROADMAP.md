# Roadmap

## Этап 1 — UI-концепция

**Статус:** спецификация утверждена как направление, идёт подготовка к прототипированию.

Документ: [UI Specification — Stage 01](DESIGN_SPEC_STAGE_01.md).

Критерии приёмки — раздел 12. Решения, которые нельзя принимать самостоятельно, — раздел 13.

### Следующие шаги

1. Анализ требований и документации. Ответы записаны в [STAGE_01_DECISIONS.md](STAGE_01_DECISIONS.md).
2. Два–три варианта компоновки Dashboard. Выбран вариант A.
3. Интерактивный HTML-прототип: [prototypes/stage-01/index.html](prototypes/stage-01/index.html). Ждёт просмотра.
4. Проверка Desktop, Tablet и Mobile выполнена на прототипе.
5. Подтверждение пользователя.
6. Только после подтверждения — UI Foundation.

Спецификация не разрешает начинать полноценную разработку приложения до этого подтверждения.

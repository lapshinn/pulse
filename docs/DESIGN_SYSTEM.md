# Design System

Визуальное направление Personal Dashboard зафиксировано в [UI-спецификации этапа 1](DESIGN_SPEC_STAGE_01.md).

**Статус:** утверждённая концепция. Кодовые токены (`styles/tokens.css`, `styles/themes.css`) ещё не заведены: они относятся к UI Foundation и появляются только после подтверждения прототипа.

Канонические правила — раздел 6 спецификации:

- палитры Light и Dark;
- типографическая иерархия;
- Lucide Icons;
- короткие анимации с учётом `prefers-reduced-motion`.

Цвета реализуются через централизованные дизайн-токены, а не значениями внутри компонентов.

Исходные таблицы остаются в разделе 6 спецификации. Принятая правка контраста и локальное подключение Inter записаны в [STAGE_01_DECISIONS.md](STAGE_01_DECISIONS.md). В коде приложения токены по-прежнему не заводятся: это UI Foundation после утверждения прототипа.

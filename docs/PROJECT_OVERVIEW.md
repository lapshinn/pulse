# Personal Dashboard

Персональный информационный центр: за 10–15 секунд увидеть основные события и показатели дня.

Утверждённая UI-концепция этапа 1: [UI Specification — Stage 01](DESIGN_SPEC_STAGE_01.md).

## Документы

- [Design System](DESIGN_SYSTEM.md) — визуальные правила; канон в разделе 6 спецификации.
- [Roadmap](ROADMAP.md) — этап 1 и условие перехода к UI Foundation.

## Разделы

Dashboard, Health, Weather, News, Settings. Состав экранов — раздел 3 спецификации.

## Платформы и темы

Desktop, Tablet, Mobile. Основная тема — Light, дополнительная — Dark. Направление — Compact Minimal.

Personal Dashboard — это развитие текущего приложения «Пульс», описанного в [README](../README.md). Существующие функции сохраняются. Новый интерфейс идёт по направлению Compact Minimal.

Решения этапа 1 и проверка MediaMetrics: [STAGE_01_DECISIONS.md](STAGE_01_DECISIONS.md).

Прототип варианта A: [prototypes/stage-01/index.html](prototypes/stage-01/index.html).
